# 实时位置中的点云显示

更新：2026-09-13。

## 问题与修复

之前只在停止采集后导出 dense_map.ply/map.ply，实时模式还会主动隐藏历史点云，因此采集中只能看见相机位置。现已增加采集过程中的实时点云快照，与相机位置同时显示。

- 稠密线程最多每 0.5 秒发布一次当前地图的在线融合预览，上限 20,000 点，不等待停止或网格建模。
- 主线程最多每 0.5 秒发布当前稀疏地图预览，上限约 6,000 点。稠密未就绪时自动显示稀疏点。
- 两个生产者分别写 live_dense_cloud.json/live_sparse_cloud.json，通过临时文件替换发布完整快照。浏览器每 0.75 秒读取 /api/live-cloud，避免将大点云塞进位姿轮询。
- 每份快照带帧号、地图 ID、地图版本和发布时间。只显示与当前遥测地图及版本一致、帧号不晚于遥测的快照；地图切换/重置会清除旧点云。短时跟踪丢失时可保留同地图旧点云，超过 3 秒标明“保留上次有效点云”，不假装更新。
- 结束采集后仍自动切换到完整导出点云的历史回放。历史在线点云保持独立参考视图，避免与最终优化轨迹混用。

这是在线估计的预览，仍可能有漂移、离群点或回环前后的重影，不保证物体完整或测量精度。没有有效稠密或稀疏点时明确等待，不生成虚构点。
